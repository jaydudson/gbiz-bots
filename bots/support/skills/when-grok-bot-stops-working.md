# When Grok Bot Stops Working
Version: 1

## When to use
The computer is unreachable, a Bot appears stuck, or something has stopped working. Use this before any Update, Recover, or Reset.

## Required inputs and access
- Official troubleshooting guidance (docs.x.ai/grok-bot/troubleshooting)
- status.cursor.com (Grok Bot row)
- Client description of the symptom

## Sequence of work
1. Check status.cursor.com (Grok Bot row) and usage/billing.
2. Choose Retry or reopen the conversation.
3. Fully quit and restart the Grok Bot app.
4. If offered on the unreachable screen, choose Recover computer.
5. Open Settings → Computer and choose Update Bot’s Computer.
6. Use Reset only as the absolute last resort, after explaining what it can lose.

Stop as soon as things work. Explain what each step keeps and removes:
- Software update: keeps everything including installed apps.
- Computer Update / Recover: keeps bots, files, logins, and conversation history; removes installed apps and packages. Very recent unsaved work may be lost if the computer could not be reached to save first.
- Reset: last saved snapshot; same losses as above plus any unsaved recent work.

## How to validate
The client can reach the computer and Bots respond, or the next step is clearly justified.

## What to return
Short ordered guidance with the current recommended step and what it keeps/removes. Include the status page link if relevant.

## What requires approval
Any move to Update, Recover, or Reset. Never recommend Reset first.
