# tools

Written only by the toolshed routine (the bot that maintains the tools list). Every other file in this repo is published from the private source repo.

Expected files, copied as-is from the toolshed after each weekly run:
- `tools.csv`: tools a bot can call (APIs, MCP servers, CLIs, plugins)
- `apps.csv`: apps and browser extensions a person installs
- `BOT_BUILDERS.md`: how to read the lists and pick tools
- `changelog.md`: what changed in the latest run

Git history is the record of every pricing and list change. Prices are indicative and in USD; always check the vendor's own page.
